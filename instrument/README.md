# Task-conditioned readiness instrument

Unchanged October 23 rubric and builder adapted from Marine Denolle's MLGeo lecture:
https://geo-smart.github.io/mlgeo-book/slides/2026/lec10_ai_ready_data.html

A research review instrument, not a validated psychometric scale or a field-wide
result. Documentation and task adequacy are separate; unknown and not applicable
are explicit. Review the declared dataset version, scientific use, learning
objective, evaluation and deployment. Do not sum a universal score. Self-supervised
pretraining, supervised target quality and pseudo-label self-training differ.
Community maturity is a separate evidence profile.

Install the root `instrument` extra to run the builder. It writes the dated DOCX
and TXT beside itself, overwriting example files; work on copies when annotating.
The Word form was previously rendered and reviewed. No private completed form is
included. The lecture is acknowledged; third-party works it references retain
their own rights.
