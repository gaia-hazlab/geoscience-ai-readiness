Task conditioned data readiness review

23 October 2026  |  Research instrument for author review

Complete one profile for a holding, version and intended use. Analysis readiness makes data interpretable and usable; AI readiness adds evidence about learning and the claimed generalization. This instrument will be refined through research. It is not an NSF requirement or a validated universal standard.

For each criterion, record evidence and the next action. Documentation: 0 = a required element is confirmed missing; 1 = incomplete; 2 = another team can verify it; U = unassessed or insufficient evidence; N/A = inapplicable with a reason. Adequacy for this use: S = supported; C = conditional; N = not supported; U = unresolved. A documented limitation can score 2 and still make a use unsupported. Do not sum grades or impose a universal pass mark.

Learning and generalization

Apply these criteria to the declared objective and model or learning method. Record measured quantities where possible. Unknown evidence remains U; explain any N/A. Preserve the scientific distinctions between measurement families, representations and source origins.

Reassess when the dataset version, model, objective or intended use changes. An analysis-ready station record can support a local study while remaining insufficient to test transfer to another region. Unlabeled continuous DAS can support a self-supervised objective; supervised phase picking additionally needs trustworthy targets and task-appropriate evaluation. Neither example receives a readiness judgment without evidence.

Basis and interpretation

Adapted from Marine Denolle, MLGeo Session 10, AI-ready data, 23 October 2026, Book section 2.13. The lecture distinguishes A1–A4 analysis prerequisites and B1–B7 learning criteria.
